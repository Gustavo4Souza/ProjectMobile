🥦 App de Legumes

Este projeto foi criado em sala de aula com o objetivo de estudar Desenvolvimento Mobile usando React Native.
A ideia é simples: um app de legumes para praticar a construção de telas, componentes e navegação.

📚 O que é React Native?

O React Native é um framework que permite criar aplicativos móveis usando JavaScript e React, funcionando tanto para Android quanto para iOS.
Ou seja, com uma base de código você consegue rodar o app em várias plataformas. 🚀

🛠️ O que aprendemos com este projeto?

Criar um projeto em React Native

Entender a estrutura de pastas

Criar e usar componentes

Estilizar com StyleSheet

Rodar o app no emulador ou no celular com o Expo Go

📱 Funcionalidades do App

Lista de legumes disponíveis

Exibição de informações básicas sobre cada legume

Layout simples e fácil de usar

(o foco é o aprendizado, então as telas são bem básicas!)

🎯 Objetivo do projeto

Este app não tem foco em design ou funcionalidades complexas.
Ele serve como material de estudo para entender o básico do desenvolvimento mobile com React Native.

👨‍🏫 Observação

Esse projeto foi feito em sala de aula para fins educacionais.
Não é um app finalizado, mas sim uma forma de praticar conceitos importantes.
